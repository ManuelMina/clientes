🔒 Seguridad

Puntos críticos a resolver

Tu sistema es poderoso pero tiene vulnerabilidades que deben resolverse antes de escalar.

🚨
API Keys en texto plano (CRÍTICO)
CREDENCIALES_AGENTE_COLOMBIA.txt contiene Groq, Notion, Google Cloud y GitHub tokens en un archivo de texto sin cifrar en OneDrive. Si alguien accede a tu cuenta de Microsoft, tiene todo. Solución: Mover a .env con dotenv + Windows Credential Manager. Tomar 1 hora.
🚨
Token GitHub en script de PowerShell (CRÍTICO)
Un token de GitHub estaba expuesto en sync-clientes.ps1 (ya se eliminó de ese archivo). Verifica que no esté en otros archivos del proyecto. Solución: Revocar y regenerar en github.com/settings/tokens.
⚠️
Google Service Account JSON expuesta
El archivo n8n-server-495201-7bc018352e59.json (credenciales de Google Cloud) está en la raíz de OneDrive. Si se sube accidentalmente a un repo público, terceros acceden a tu Google Sheets. Solución: Moverlo a carpeta fuera de OneDrive + agregar al .gitignore global.
⚠️
Bot depende del PC encendido
WhatsApp bot y n8n mueren si cierras el portátil o hay un corte de luz. MilenaShoes pierde ventas automáticas ese tiempo. Solución: Railway.app a $7 USD/mes — 5 min de setup.
✅
Puntos fuertes de seguridad
✓ Windows Credential Manager para GitHub sync · ✓ Números de admin whitelisteados en WhatsApp bot · ✓ .gitignore en repo de clientes · ✓ GitHub Pages sin backend expuesto
